# AI-Business-Case
The project integrates Design Thinking (Empathize → Define → Ideate → Prototype → Test) with the Business Model Canvas (BMC v1.2), a NaBC elevator pitch, and an adoption plan (digital culture, adaptive leadership, transformation, governance, and metrics).

This is a comprehensive AI Business Case ready for pilot. By me and my classmate for a Uni-level project. Started off strong with a survey of 50+ Uni students (Quotes, survey scripts, synthesis tabled found in file named 'Evidence Appendix'.  Identified the problem - Need for a centralized, intelligent system that brings clarity and coordination across academic and campus engagement. Our solution - UniMentor - Concept: AI Student Companion (Academic + Engagement Layers) A simple, unified interface where students see their daily schedule, receive AI-generated recommendations, and get automated academic feedback. 

Core functions and low-fi prototype avalaible in 'BMC' file. 

Crafted JTBD (Job to be Done) and HMW (How Might we). 

Designed a Low-fi prototype and an early test with KPI and decision threshold. 

Translated findings into a coherent Business Model Canvas v1.2 with plausible financial logic. File named 'Execitive Brief' contains a clear NaBC pitch. Presented an adoption plan: digital culture, leadership, change enablement, OKRs, governance & data.

'Test Card' file contains Hypothesis, KPI, threshold, time window, risks, our next decision.
